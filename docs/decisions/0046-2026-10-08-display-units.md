# 0046 — Display units: cm by default, chosen per user

- **Date:** 2026-10-08
- **Status:** Accepted

## Options considered
- **cm default, per-user choice** ✅
- Fixed cm everywhere
- Tenant-wide setting

## Decision
- Display defaults to **centimetres**. Each user can switch to **m** (2 decimals) or **mm** in their preferences, which are stored server-side on the person or session profile.
- **Input accepts explicit suffixes** regardless of the display unit: `350`, `350cm`, `3.5m` and `3500mm` are all accepted. A bare number is read in the user's display unit.
- Angles are shown in degrees with one decimal. Storage stays in decidegrees.
- Storage and the API are always integer mm ([0029](0029-2026-10-08-geometry-representation.md)).

## Consequences
- Screenshots may show different units depending on who took them. Exports and prints show the unit next to every value.
- A single formatting/parsing module in the frontend is shared by inline input, the panel and labels ([0045](0045-2026-10-08-dimension-entry.md)).
