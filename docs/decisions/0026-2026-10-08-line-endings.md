# 0026 — Line endings: normalize to LF

- **Date:** 2026-10-08
- **Status:** Accepted

## Options considered
- **Normalize to LF via `.gitattributes`** ✅
- Leave per-machine Git defaults

## Decision
The repository stores text files with **LF** line endings, enforced by `.gitattributes`. Windows-native scripts (`*.bat`, `*.cmd`, `*.ps1`) use CRLF. Common binary formats (images, fonts, glTF/GLB) are marked binary.

## Consequences
- Consistent content across Windows developers, Linux containers and CI.
- Editors on Windows should be set to LF for this repo (`.editorconfig` to be added with the code scaffolding).
