# 0132 — Ctrl+V pastes at the pointer, Ctrl+Shift+V next to the original

- **Date:** 2026-11-09
- **Status:** Accepted
- **Refines:** [0049](0049-2026-10-08-bulk-layout-tools.md) (copy and paste)

## Context
0049 gave paste two choices: "same coordinates" and "place at cursor". The editor put them on Ctrl+V (same coordinates) and Ctrl+Shift+V (at the pointer).

The owner wants these swapped. The pointer is where people look, so the plain key should paste there. Pasting exactly on top of the original also hides the copy: it looks as if nothing happened. The other key should paste "like Paint": next to the original, shifted on the diagonal so the copy shows.

## Decision
- **Ctrl+V pastes at the pointer.** The copy's centre goes where the pointer is, on the grid when snapping is on. This is what Ctrl+Shift+V did before.
- **Ctrl+Shift+V pastes next to the original:** 50 cm down and 50 cm to the right of it on the screen. 50 cm is easy to see at any zoom, and it's whole steps of every grid size, so the copy stays on the grid. It doesn't change with the grid.
- **The same in Hebrew.** The plan isn't mirrored in Hebrew; it's the same drawing for everyone. So the same keys give the same result in both languages.
- **Pasting again moves on.** Each Ctrl+Shift+V of the same copy goes another 50 cm down and to the right, like Paint and most editors. Three pastes make a staircase of three copies, none on top of another. A new Ctrl+C starts again at 50 cm.
- **On another floor, Ctrl+Shift+V pastes in the same place,** with no shift. There the original isn't on the plan to hide the copy, and repeating a layout on floors 2–8 needs the same coordinates (0049). A copy made before this change doesn't say which floor it came from, so it too pastes in the same place.

The owner chose each of these from options, on 2026-11-09.

## Consequences
- The help that appears after Ctrl+C, and the Keyboard and mouse sheet (0130), describe the new keys in English and Hebrew.
- A copy now records the floor it came from. Copies stay readable both ways: the field is optional.
- The count of pastes is kept only in this browser tab. Pasting from another tab starts again at 50 cm.
