# 0091 — Move the backend to Python 3.14

- **Date:** 2026-10-15
- **Status:** Accepted
- **Supersedes:** the Python version in [0065](0065-2026-10-08-python-version-and-dev-tooling.md) (its tooling choices stand)

## Context
[0065](0065-2026-10-08-python-version-and-dev-tooling.md) chose Python 3.13 and left moving to 3.14 as "a later, explicit decision once all native wheels (asyncpg, Shapely, GEOS) are confirmed". Dependabot then proposed moving only the container image to `python:3.14-slim`, which would have run production on a version that development and CI don't use.

Checked before deciding: asyncpg 0.32, Shapely 2.2 (GEOS 3.14.1) and every other dependency install from ready-made wheels on 3.14; all 192 backend tests pass on 3.14, database tests included; the production image builds and starts.

## Decision
| Question | Options | Chosen |
|---|---|---|
| Python version | **3.14 everywhere** / stay on 3.13 / only the image on 3.14 | **3.14 everywhere**, changed together: the image (`python:3.14-slim`), `requires-python = ">=3.14,<3.15"`, `backend/.python-version` (which CI's `setup-uv` follows), ruff's `target-version` and mypy's `python_version`, and `uv.lock`. |

## Consequences
- Development, CI and production run the same Python.
- **3.14 language changes in our code:** annotations are evaluated lazily (PEP 649), so ruff removes now-needless quotes from forward references; and `except A, B:` without parentheses is allowed (PEP 758), which ruff's formatter now writes. It means the same as `except (A, B):`, despite looking like Python 2.
- Future minor versions follow the same rule: move everything at once, after checking the native wheels.
