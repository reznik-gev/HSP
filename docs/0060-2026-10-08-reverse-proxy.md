# 0060 — Reverse proxy & TLS: Nginx

- **Date:** 2026-10-08
- **Status:** Accepted

## Options considered
- Caddy (automatic HTTPS)
- **Nginx** ✅
- Traefik

## Decision
Nginx is the single entry point and gives everything **one origin** ([0038](0038-2026-10-08-api-authentication.md)):

| Path | Upstream |
|---|---|
| `/` | Frontend static build (served directly by nginx, SPA fallback to `index.html`) |
| `/api/` | `api` (FastAPI) |
| `/auth/` | `keycloak` (configured with that relative path) |
| `/metrics`, `/healthz` | **not exposed** (internal only) |

- **TLS:** operators provide a certificate and key, from a corporate CA or public. On first install, `hsp install` generates a self-signed certificate so the stack works immediately, and warns until it's replaced. HTTP redirects to HTTPS. TLS 1.2+ only.
- **Security headers** are set centrally: a strict `Content-Security-Policy` (required by [0038](0038-2026-10-08-api-authentication.md)), HSTS, `X-Content-Type-Options`, `Referrer-Policy`, `frame-ancestors 'none'`.
- Maintenance page during upgrades ([0056](0056-2026-10-08-upgrades-and-migrations.md)). Gzip/Brotli for floor-plan payloads ([0036](0036-2026-10-08-floor-plan-io.md)). Request body limits sized for CSV imports.

## Consequences
- Familiar to enterprise ops teams, with no automatic certificate management. Certificate renewal is the operator's job, documented in the guide.
- The nginx config is a versioned template in `/deploy`, with site-specific values coming from `.env`.
