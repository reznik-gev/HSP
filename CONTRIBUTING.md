# Contributing to HSP

Thanks for your interest. HSP is **proprietary, source-visible software** (see [LICENSE](LICENSE) and [decision 0071](docs/decisions/0071-2026-10-08-license-and-contributions.md)).

## Pull requests from outside contributors
**External pull requests are not accepted at this time.** They'll be closed without review. This keeps copyright ownership in one place while the licensing model may still evolve. The policy will be revisited if a community forms.

## What is welcome
- **Bug reports and feature ideas:** open a GitHub issue.
- **Security vulnerabilities:** never use a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting.
- **Licensing inquiries:** open an issue titled "Licensing inquiry".

## For maintainers
The development workflow is documented in the [README](README.md#contributing-0064) and the decision records:
- [0064](docs/decisions/0064-2026-10-08-branching-workflow.md): branches and PRs
- [0069](docs/decisions/0069-2026-10-08-rebase-merges.md): rebase-only merges
- [0070](docs/decisions/0070-2026-10-08-ci-gate-job.md): the required `ci-ok` check
